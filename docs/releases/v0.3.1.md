## Summary

Xanthos 0.3.1 is a compatible patch release for the .NET 10 portable and Windows
package assets.

## Highlights

- Decode the 398 documented CP932 aliases in official record text, including
  roman numerals in BT lineage descriptions. Original bytes and located errors
  for malformed or undefined sequences are preserved.
- Make CP932 test fixtures independent of global encoding registration and make
  event-subscription tests wait for acknowledged delivery.
- Add a measured managed-coverage badge, structured issue/PR templates and
  automatic contribution metadata checks.

## Compatibility and migration

This is a compatible patch for `net10.0` and `net10.0-windows`. Portable parsing
does not require JV-Link. COM use requires Windows, an x64 process and JV-Link
5.0 x64 with its service key registered; see the
[functional API contract](https://github.com/cariandrum22/Xanthos/blob/v0.3.1/docs/functional-api.md).

## Verification

- **Managed checks:** Required hosted Fast/Coverage checks ran on Linux, macOS
  and Windows; [release verification #42](https://github.com/cariandrum22/Xanthos/issues/42)
  records the source, CI and publication evidence.
- **WindowsManaged:** SDK-free Windows boundary verification was performed.
- **Native COM:** The candidate's real COM gate recorded **14 passed, 1 failed,
  zero skipped**. `JVOpen` returned `-413` when reopening a session; the original
  failure is retained.
- **Package consumption:** Independent consumers verified both package assets.
  The candidate parsed all 18 previously quarantined BT records without changing
  their raw bytes.
- **Tag signature:** The original publication used an unsigned annotated tag. Its
  [target commit](https://github.com/cariandrum22/Xanthos/commit/a8998a20662d6d68b126e4c6aecc51cfdea9f404)
  is verified. This historical release predates the signed-tag publication gate;
  see the [release tag](https://github.com/cariandrum22/Xanthos/releases/tag/v0.3.1)
  for its current signature status.

## Known limitations

The native `-413` result is consistent with the previously accepted
[SDK-COM-413 limitation](https://github.com/cariandrum22/Xanthos/blob/v0.3.1/docs/sdk-known-limitations.md).
This release does not fix native communication failures or claim that all
candidate COM checks passed. SDK consent remains interactive, and live-event
and playback limitations are unchanged.
